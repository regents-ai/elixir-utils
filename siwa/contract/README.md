# Signed agent request contract

Generated by `mix siwa.contract` in `siwa/siwa-elixir` from `Siwa.Contract` and
`Siwa.Contract.Fixtures` (compiled only in dev and test). Do not edit these files by hand; `mix check` fails when
they differ from the library.

- `contract.json`: the headers, covered components, signature parameters and
  lifetime every SIWA signer and verifier follows, how a query string is handled
  (`query`), and what the sign-in server answers for each refusal (`refusals`).
  Its sha-256 is the contract id.
- `fixtures.json`: requests signed by test key `0x…01` at a fixed time and nonce,
  with the cases a site or the sign-in server refuses and the ones it accepts.
  `Siwa.Contract.Fixtures` explains each field.

The Python and JavaScript signers generate their contract resources and test
fixtures from these two files.
